Per utilizzare il file app.py, scarica ed estrai la cartella compressa presente nella reposistory, apri la pagina index.html con un browser e clicca sul pulsante "Download". Verrai reindirizzato alla pagina download.html, dove potrai cliccare sull’immagine del bottone per avviare il download del file compresso app.zip. Una volta scaricato, estrai il contenuto del file .zip, quindi apri il file con un programma in grado di eseguirlo ed eseguilo nel terminale
Assicurati di avere Python installato sul tuo computer.
Nel caso il download dell'applicazione non dovesse funzionare all'interno di questra reposistory è presente il file app.py eseguibile in python
