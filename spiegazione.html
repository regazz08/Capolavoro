Meteo

Spiegazione del codice

Il codice python ha lo scopo di fornire informazioni meteo attuali e previsioni per una città specifica. Utilizza l'API di OpenWeatherMap per ottenere i dati meteo e li visualizza in modo leggibile nel terminale. In base alla scelta dell'utente si potranno visualizzare i dati meteo attuali, le previsioni per i prossimi 5 giorni o entrambi.



Librerie

Per la realizzazione del codice python e l'abbellimento degli output sono state utilzzate le seguenti librerie:

  • Request: libreria necessaria per il funzionamento corretto del codice;serve per raggiungere la pagina dove sono salvati i dati meteo che verranno esportati in python, riesce in questo compito grazie all'API Key personale dell'utente
  • Tabulate: libreria utilizzata per l'abbellimento degli output nel terminale,consente la realizzazione di tabelle nelle quali verranno visualizzati i dati
  • colorama: libreria utilizzata per l'abbellimento degli output nel terminale,consente di colorare le scritte per rendere il testo più leggibile


Funzionamento del codice

  1. Richiesta all'utente: L'utente inserisce il nome della città della quale vuole conoscere informazioni
  2. Seconda richiesta : L'utente inserisce l'opzione che desidera (visualizzare le previsioni,i dati attuali,entrambe o uscire dall'applicazione)
  3. Recupero delle informazioni attuali attraverso l'utilizzo dell'API Key:
    • In base alla scelta dell'utente se seleziona di visualizzre i dati attuali la funzione get_attuale(citta, api) costruisce un URL con la città e l'API
    • Verifica la validità della risposta (status code 200), estrae i dati su temperatura, umidità, pressione, descrizione del meteo e l'icona corrispondente alla descrizione meteo
  4. Recupero delle previsioni attraverso l'utilizzo dell'API Key:
    • Se invece l'utente scegliesse di visualizzare le previsioni attraverso la funzione get_previsioni(citta, api) ottiene le prime 5 previsioni future
  5. Rappresentazione delle informazioni:
    • Le informazioni vengono formattate in una tabella con l'ora, la temperatura, l'umidità e la descrizione del meteo
    • Se l'utente ha scelto di visualizzare i dati attuali e le previsioni, entrambe le tabelle vengono stampate
    • Se l'utente ha scelto di visualizzare solo i dati attuali o solo le previsioni, viene stampata solo la tabella corrispondente
    • Le tabelle vengono stampate nel terminale attraverso libreria Tabulate


API KEY (openweathermap)

Una API Key è una stringa che identifica un utente o un'applicazione quando si accede a un'API (Application Programming Interface). Le API Key sono utilizzate per verificare le richieste e garantire che solo gli utenti autorizzati possano accedere a determinati dati.
